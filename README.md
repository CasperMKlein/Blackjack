# Blackjack
Simple Blackjack game

Der skal indledningsvis udformes og afleveres en kravspecifikation og arbejdsplan. Der skal 
arbejdes med git, og der skubbes hyppigt til et remote repository, så vi kan følge udviklingen. 
Der vedlægges en readmefil til beskrivelse af projektet og dets softwarearkitektur. Det skal 
også fremgå, hvordan spillet bygges og afvikles.
Der skal implementeres enhedstest (en. unit tests) for programmet i en sådan grad, at 
mindst 95 % af kildekoden er dækket.
Der afleveres på GitHub. Foruden selve projektet skal arkivet indeholde en beskrivende 
README.md-fil i roden. Denne skal blandt andet indeholde eller henvise til
• beskrivelse af projeket
• udførlig beskrivelse af, hvordan projektet bygges, testes og køres
• beskrivelse af den implementerede softwarearkitektur
• mindst ét UML-diagram
